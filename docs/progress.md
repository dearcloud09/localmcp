## 이번 변경: M2B-02a/02b
기준 커밋: `aaeb0cc70e338f6da3e0b0a64842df3ff1dfa466`.

`src/core/sensitive-paths.ts`는 이름 기반 경로 정책과 유한한 디렉터리 변경 사전 검사를 제공한다. Workspace의 경로 검사, 읽기, 목록/탐색, 이동/삭제에 연결했다. `.env`/`.env.*`, 주요 자격증명 디렉터리, `.git`, `.localmcp`, 일반 키 형식 등을 제한한다. 하드링크 내용 읽기·이동/삭제와 심볼릭 링크 이동/삭제도 거부한다. 상위 폴더를 통째로 옮기거나 지워서 보호 파일을 건드리는 경로를 검사한다. 사전 검사 상한은 10,000개 노드/깊이 64이며 넘어가면 변경하지 않는다. 빈 폴더의 비재귀 삭제는 rmdir를 사용하도록 맞췄다.

`src/core/external-tool-policy.ts`와 실제 config/McpLoader를 연결했다. 활성 서버에 exact-name allowedTools가 없으면 시작을 거부하며 모든 서버 설정을 검증한 후 프로세스를 시작한다. 원격 readOnlyHint나 새로 발견한 도구 이름은 권한을 추가하지 못한다. 이름은 사전 허용되고 첫 관찰의 설명·입출력 스키마·annotations를 현재 연결 동안 고정한다. 관찰된 변경은 격리하고 목록 실패 시 예전 실행 목록을 남기지 않는다. 최대 64개 목록 페이지/4,096개 도구 및 반복 cursor를 제한한다. 동일 서버의 겹친 발견 요청은 하나로 합친다.

기존 mcp/hot reload/relay fixture는 필요한 echo/second/new_tool 이름을 명시했다. 테스트를 삭제하거나 no-op으로 만들지 않았다. 새 외부 의존성·하위 서버·모델·매 호출 네트워크 재발견은 추가하지 않았다. 기존 CLI 어댑터/범용 명령 실행 코드는 변경하지 않았다.

## 이번에 실제 실행한 검사
Linux / Node 22.16.0 / TypeScript 5.8.3. 새 파일/경로 검사 20개, 새 MCP 정책 14개, 기존 독립 43개를 **같은 Node 테스트 실행**에서 검사해 77개 통과, 실패/취소/건너뜀 0. 해당 소스/테스트에 엄격한 TS 검사를 적용했다. 변경 TS 파일 11개의 문법 검사 및 새 JS fixture 문법 검사도 수행했다.

변경 전 Workspace를 별도로 컴파일해 임시 디렉터리에서 비교했다. 가짜 `.env` 내용 읽기와 그 부모 폴더 이동은 원본에서 허용됐고, 새 구현은 모두 SENSITIVE_PATH로 거부했다. 실제 비밀이나 사용자 폴더는 사용하지 않았다.

SDK/config/stdio 신규 통합 검사 5개는 작성했으나 실행하지 못했다. Git clone은 github.com DNS 오류, npm ping은 registry.npmjs.org EAI_AGAIN으로 실패했다. 로컬 작업본은 필요한 원격 소스와 업로드 패키지에서 검증한 일부 파일이지 전체 clone이 아니다. 현재 전체 check/build/test·기존 프로필 suite·SDK/Worker·macOS/Windows·실제 ChatGPT는 미검증이다. SDK를 대역으로 바꿔 실제 연동이라고 표시하지 않았다. 이전 M1 64개/M2a 28개/앞선 67개와 합산하지 않는다.

## 남은 경계와 다음 순서
이름 기반 필터는 일반 소스에 들어 있는 비밀값을 탐지하지 않으며 `.env.example`과 공개 인증서의 `.pem`도 보수적으로 차단한다. 설정으로 임의 해제하는 옵션은 이번에 넣지 않았다. 같은 사용자 프로세스가 검사 사이에 파일시스템을 교체하는 공격, 이름을 바꾼 단일 링크 비밀 복사본까지 방어한다고 주장하지 않는다.

MCP 도구 허용은 그 서버의 실행 파일·구현·인자 효과를 신뢰할 수 있다는 증명이 아니다. 설명을 그대로 둔 채 내부 행동을 바꾸는 것은 감지하지 못한다. 허용된 셸/하위 MCP와 Git 출력은 파일 도구 필터 밖이다. 해당 경로/환경/네트워크 격리는 M2B-03에 남긴다. 관찰된 명세 변경의 격리는 현재 policy 인스턴스 범위이며 운영자가 검토 후 서버를 재시작하면 새 기준이 된다. 실행 중인 호출 취소/롤백과 즉시 권한 회수는 제공하지 않는다.

다음 우선순위는 누적 SDK/시작/중계 통합 검증과 OS 격리 실행이다. 코드·테스트·Git 문서·PR을 함께 갱신한다. CI 과금, 공개 터널, 계정 변경, 사용자 맥 실행, main 병합은 수행하지 않는다.
