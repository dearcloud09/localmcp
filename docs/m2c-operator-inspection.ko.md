# M2C-02b-3a — 운영자 읽기 전용 기록 점검

상태: 로컬 검토본 구현·독립 검증. **원격 실행 코드에는 미반영**이다. 기준 원격 문서 커밋은 `10a7eb72666e85f7e87698f8f8704ae0de21c5cc`다. 이전 업로드 보안 차단을 재시도·우회하지 않았다.

## 목적과 범위
기록소에 무엇이 남았는지 안전하게 조사한다. 시작 기록만 있는 작업을 중단된 작업으로 단정하거나, 성공 기록을 현재 파일 상태의 증명으로 사용하지 않는다. 이 단계는 조회 도구이며 복구·재실행 도구가 아니다.

- 기존 기록소만 읽는다. 없거나 손상된 namespace를 새로 만들거나 메모리 방식으로 대체하지 않는다.
- 원래 ID를 알지 못해도 해시 기반 참조와 상태의 목록을 볼 수 있다. 원래 ID를 복원하지 않는다.
- 페이지당 최대 200개, 기록소 설정 용량 이내로 열거한다. 원자적 snapshot이 아니고 페이지별 결과다. 페이지 간 새 작업이 추가될 수 있으므로 전체 건강 상태를 단정하지 않는다.
- 남아 있는 할당 잠금은 존재를 보고할 뿐, 소유자 생존 여부나 오래된 잠금인지 추정하지 않는다. 삭제하거나 획득하지 않는다.
- 기본 출력에는 실제 경로·작업 ID·fingerprint·파일명·영수증의 전후 해시·원문을 넣지 않는다. 해시 참조 자체는 익명화나 암호화 보장이 아니다.

## 상태 해석
| 관찰 | 해석 | 자동 행동 |
|---|---|---|
| 성공 완료 기록 | 과거 성공 영수증 | 재실행 없음 |
| 실패 완료 기록 | 실패했으나 부작용이 없다는 뜻은 아님 | 재실행 없음 |
| 시작만 있거나 기록 손상 | 진행 중/중단/결과를 구별하지 못함 | 운영자 검토, 변경 없음 |
| 해당 ID 없음 | 기록 부재이지 과거 효과 부재의 증명이 아님 | 재실행 권한을 부여하지 않음 |
| 링크·권한 위반·예상 밖 항목 | 점검 차단 또는 검토 필요 | 읽기 우회·chmod·삭제 없음 |

## 선택적 현재 파일 대조
알고 있는 작업 ID와 정확한 workspace를 지정한 경우, 성공 영수증에 기록된 파일을 기존 Workspace 정책으로 읽어 현재 SHA-256과 비교할 수 있다. 결과는 미요청/해당 없음/일치/불일치/읽기 불가다. 실제 경로는 대소문자를 유지하고 ID scope만 정규화한다. `.env` 같은 보호 경로를 읽는 우회로 만들지 않는다.

일치해도 누가 변경했는지, 정확히 한 번 실행했는지 또는 이후에 변경되지 않을지는 증명하지 않는다. 불일치해도 과거 성공 기록을 실패로 바꾸거나 파일을 덮어쓰지 않는다.

## 실행 인터페이스와 종료 코드
검토본에는 `src/recovery-inspect.ts`와 독립 컴파일 결과가 있다. 기존 런타임 설정을 실행하지 않고 명시적인 directory/workspace/capacity만 받는다. 선택 인자는 limit/after와 operation/scope/compare-current다. 상대 경로·알 수 없는 플래그·중복 단일 인자는 거부한다. reset/retry/unlock/force 플래그는 없다.

종료 코드 0은 **요청한 조회가 끝남**, 2는 검토가 필요한 관찰, 1은 잘못된 입력/namespace 등으로 점검이 차단됨이다. 어느 코드도 작업을 재실행하라는 승인이 아니다. CLI는 서버나 MCP 도구에 등록하지 않았고 사용자 맥에 설치하지 않았다.

## 실제 검사와 한계
새 33개와 기존 121개를 같은 실행에서 검사해 154개 통과, 실패/취소/건너뜀 0. 실제 CLI 자식 프로세스와 실제 SIGKILL 후 조회, 파일/기록 불변, 용량/페이지/권한/링크/손상/기밀 출력 검사를 포함한다. 독립 TS strict 검사를 통과했다. [검증 JSON](validation/m2c-inspection-local.json)

읽기는 파일시스템 접근 시간(atime)을 갱신할 수 있다. 검사에서는 파일 집합·내용·모드·inode·mtime·ctime을 대조했고 atime을 불변이라고 주장하지 않는다. 같은 OS 사용자의 악의적 파일 경합이나 전원 장애는 방어 범위가 아니다. 실제 SDK/서버·macOS·Docker 검증은 남아 있다. 이후 복구 명령은 별도 설계·권한·검증이 필요하며 이번에 구현하지 않았다.
