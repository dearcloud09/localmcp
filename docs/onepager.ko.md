ChatGPT가 판단하고 포크가 실행·권한·기록을 맡는다. 기능 모듈은 내부 함수·기존 CLI·필요한 하위 MCP를 선택한다. 별도 서버나 모델을 의무화하지 않는다.

`ChatGPT → MCP → 공통 코어 → 파일 / Git / 검사 / 전문 도구`

## 이번 연결 계약
설정 생략은 기존 메모리 동작이다. 영속 모드는 프로젝트 밖 소유자 전용 기록소를 명시하고 별도 create-only 초기화를 해야 한다. 실제 런타임은 기존 기록소만 열며, 없거나 손상됐으면 실패한다.

HTTP/stdio 런타임의 Workspace가 같은 journal을 사용하도록 연결 코드를 작성했다. 영속 모드·기록소·용량·workspace 집합 변경은 live reload에서 거부하고 재시작 검토를 요구한다. 정상적인 읽기/쓰기 권한 변경은 별도이며 이전 성공 요청의 재전달도 현재 권한 검사를 거친다. 새 MCP 서버·도구 호출 왕복은 추가하지 않았다.

## 검증과 반영 상태
새 독립 30개와 이전 91개를 **같은 실행에서 121개 통과**, 실패·취소·건너뜀 0. 독립 소스 strict 검사와 변경 TS 13개 문법 검사 통과. 실제 프로세스 재열기·임시 파일·공통 dispatch/Workspace를 검사했다. SDK용 새 7개는 작성했지만 의존성 부재로 미실행이다. [검증 기록](validation/m2c-runtime-local.json) · [연결 계약](m2c-runtime-integration.ko.md)

**새 실행 코드는 로컬 검토 보관본에만 있다.** 이전 보안 차단을 재시도·우회하지 않았고 Git에는 문서/검증 기록만 갱신했다. 기존 원격 E0/E1은 유지하지만 새 코드로 일반화하지 않는다. 전체 pinned 검사·빌드·SDK/중계·macOS·실제 Docker는 남아 있다.

다음은 허용된 코드 반영 경계와 전체 통합 검증이다. 기록 보호는 operationId/expectedSha256을 제공한 edit_file/apply_patch에 한정되며 일반 쓰기·외부 에디터·셸까지 보호하지 않는다. 파일 변경과 로그의 원자적 트랜잭션·전원 장애·자동 복구를 보장하지 않는다. Git 문서가 기준이며 MIT 고지를 유지한다. PR Draft 유지; CI/과금·공개 중계·배포·main 병합 없음. 사용자 맥 작업은 지금 요구하지 않는다.
