## 최소 검증 경로
`npm run verify:minimum`은 설치된 원본 의존성으로 검사·빌드·전체 테스트 후 실제 SDK와 서버를 stdio로 연결한다. 임시 프로젝트에서 읽기 전용 거부, 민감 파일 비노출, 소스만 수정, 같은 테스트 3실패→3통과, 오래된 해시 patch 거부를 확인한다. 테스트/비밀 가짜 파일은 불변이어야 한다. 성공 표시는 `MINIMUM_LOCAL_OK`이며 **Docker·실제 ChatGPT 성공을 뜻하지 않는다**.

`-- --image sha256:<검토한 로컬 이미지 ID>`를 추가하면 실제 Docker 검사도 필수 관문으로 포함한다. 성공 표시는 `MINIMUM_LOCAL_AND_SANDBOX_OK`. 어느 모드도 실제 ChatGPT 계정 연결을 검증하지 않는다. [실행 안내](minimum-verification.ko.md)

## 실행 정책과 경계
파일 도구는 기본 읽기 전용이다. `run_check`는 `checks`를 명시한 경우만 노출하며, 기존 셸을 켤 필요가 없다. 검사 정의·이미지·argv는 운영자 설정에서 정하고 모델은 검사 이름만 선택한다. 파일 읽기 권한이 필요하다.

Docker 경로는 민감 이름을 제외한 유한한 복사본만 읽기 전용으로 마운트하고 검사는 용량 제한 tmpfs에서 실행한다. 로컬 context·이미지 ID 고정·pull 금지·네트워크 없음·비루트·권한 제한·자원 상한을 적용하고 실제 생성된 컨테이너 설정을 검사한다. 검사 뒤 소유한 컨테이너를 제거하며 실패/타임아웃/정리 미확인을 구분한다. 원본으로 결과를 복사하지 않는다. **기존 셸과 하위 MCP를 자동으로 격리하는 수정은 아니다.**

## 검증·문서 기준
이번 독립 실행에서 **65개 통과**: 새 스냅샷 14, Docker CLI 대역 수명주기 7, 검증 실행기 11, 기존 CLI/Git 15·registry 18. 대역 검사를 실제 Docker 검증으로 표시하지 않는다. 독립 TS strict 검사 통과. 전체 SDK/원본 의존성·실제 Docker·macOS·사용자 ChatGPT는 별도 미검증. [실행 기록](validation/minimum-preparation-local.json)

**Git의 이 문서와 진행표가 기준**이다. CI는 사용자 확인 한도 초과로 보류하며 PR은 Draft다. main 병합·공개 터널·계정/과금 변경·이미지 다운로드·패키지 배포는 하지 않는다. 다음 관문은 기능 추가가 아니라 E0/E0-D의 실제 실행 결과다. MIT 고지를 유지한다.
