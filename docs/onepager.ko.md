## 목표와 구조
ChatGPT가 코딩 판단을 하고, 포크가 로컬 실행·권한·작업 기록·결과 전달을 담당한다. 기능을 모듈화하되 별도 서버를 의무화하지 않는다.

`ChatGPT → MCP 입구 → 공통 코어 → 기능 모듈 → 내부 함수 / 기존 CLI / 필요한 하위 MCP`

파일 수정은 내부 코드, Git·테스트·빌드는 기존 CLI를 우선 활용한다. 전문 기능에만 하위 MCP를 사용하고, 자주 쓰는 도구는 직접 노출한다. 불필요한 모델·통신·발견 호출은 늘리지 않는다.

## 이번에 달라진 실행 규칙
설정이 없거나 프로젝트를 명시하지 않으면 시작하지 않는다. 홈/루트/주요 자격증명 디렉터리와 겹치는 workspace, workspace 내부 설정 파일을 거부한다. 셸·지속 프로세스·Skills 자동 활성화를 없애고 환경변수의 권한 확대를 거부한다. 초기 시작과 설정 재로딩이 같은 정책을 사용하며, 에이전트는 등록/네트워크 전에 검증한다. 기존 설정은 자동 수정하지 않는다. [M2b 적용 안내](m2b-runtime-policy.ko.md)

파일 쓰기는 여전히 가능하고 파일별 비밀정보 필터는 미완성이다. 명시적으로 켠 셸/하위 MCP는 호스트에 접근할 수 있다. 시작 검사는 OS 격리도, 악의적인 같은 사용자 프로세스에 대한 방어도 아니다.

## 검증과 문서 관리
**이 파일과 `progress.md`의 Git 버전이 기준이며, 다운로드 파일은 해당 시점의 사본이다.** 코드 변경과 함께 단계·근거·미검증을 갱신한다. 현재 정책/독립 모듈의 엄격한 TypeScript 검사와 67개 테스트는 통과했지만, 전체 저장소 검사·SDK/Worker·macOS/Windows·실제 ChatGPT는 별도 미검증이다. 이전 64/28개와 이번 67개를 더해 전체 통과 수로 표시하지 않는다. [검증 기록](validation/m2b-policy-local.json)

CI는 사용 한도 초과로 보류(사용자 확인). 추가 비용·재실행 없이 진행하며 PR은 Draft로 유지한다. `main` 병합·공개 터널·계정/과금 변경·패키지 배포는 자동 수행하지 않는다. 다음 개발 우선순위는 읽기/쓰기 분리와 민감 경로 정책이다. 자체 IDE·언어 서버·다중 에이전트·브라우저 자동화는 범위 밖이며 MIT 고지를 유지한다.
