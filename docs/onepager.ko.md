## 현재 판단 — 실행 경로 식별, 연결 복구는 아직 미실행
사용자가 해시 확인된 읽기 전용 진단의 JSON을 제공했다. E1 제어 소켓은 `ECONNREFUSED`, 제한된 관련 프로세스 탐색은 0건이었다. 기존 등록·연결 기록은 존재했다. 현재 관측된 E1 제어 경로는 사용 불가하지만, 과거 커넥터 502의 발생 계층·종료 원인까지 확정하지 않는다.

R1은 `4a5e66c`의 clean checkout이며 소스·디스크 빌드에 M2c 문자열이 없다. R2는 `8dd7876`의 clean checkout이며 M2c 문자열과 recovery-init 빌드가 있다. Node v23.11.0, npm 메타데이터 11.4.2와 주요 의존성 메타데이터를 확인한 사용자 보고다. 실행 중인 프로세스의 빌드 증명은 아니다.

원격을 직접 비교한 결과 R2 커밋에서 세션 시작 원격 HEAD `2ad5944`까지 차이는 docs 4개뿐이다. 따라서 이번 검증을 위해 R1을 갱신하거나 R2에서 pull·재빌드·최소 검사를 반복할 필요는 없다. 로컬 진단의 non-doc 비교 null과 이 원격 비교를 구분한다. Docker CLI는 현재 PATH에서 발견되지 않았고, 시스템 전체 미설치나 daemon 부재를 확정하지 않는다.

## 유지하는 범위와 한계
이전 E0/파일-only E1 및 `M2C_LOCAL_CHECKS_OK`는 당시 근거 수준을 유지한다. 새 코드 실계정, 실제 Docker, 전체 영속 lifecycle로 확대하지 않는다. memory recovery는 M2c 부재가 아니며 durable lifecycle은 별도 관문이다.

M1·M2a·M2b 파일/프로필/정책과 M2c 큐·해시·작업 ID·영속 기록·읽기 전용 점검의 기존 구현 상태는 유지한다. 교차 프로세스 다른 ID 잠금, 수동 복구, 다중 파일, 프로세스 복구, 전원 장애 보장, 실과제 성능, 전체 실행 격리는 미완료다.

이번 Git 변경은 새 진단 근거와 현재 실행 계획의 문서 갱신뿐이다. 과거 검증 JSON과 E1 증거는 변경하지 않는다. 소스·테스트·의존성·설정·권한·main·배포·CI 과금 변경 없음. PR Draft·MIT 고지 유지. 실제 감사·기동·도구 호출 성공은 다음 실행 결과를 받은 뒤에만 기록한다.
