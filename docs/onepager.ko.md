## 목표와 구조
ChatGPT가 코딩 판단을 하고, 포크가 로컬 실행·권한·작업 기록·결과 전달을 담당한다. 모듈화가 별도 서버를 의무화하지 않는다.

`ChatGPT → MCP 입구 → 공통 코어 → 기능 모듈 → 내부 함수 / 기존 CLI / 필요한 하위 MCP`

파일 편집은 내부 코드, Git·테스트·빌드는 기존 CLI를 우선 활용한다. 전문 기능만 하위 MCP로 확장한다. 불필요한 모델·통신·발견 호출을 늘리지 않는다.

## 현재 정책
명시적 프로젝트와 workspace 밖 설정이 필요하다. 파일 권한은 기본 읽기 전용이며 쓰기는 명시적으로 허용한다. 편집용 init/demo는 읽기·쓰기를 명시하고 셸/프로세스/Skills/외부 MCP는 끈다.

파일 도구는 `.env*` 중 `.env`와 `.env.` 접두 이름, 자격증명·키·런타임 경로 등을 제한하고 검색/목록에서 제외한다. 보호 파일이 든 상위 폴더의 이동/삭제도 사전 거부한다. **일반 소스에 들어 있는 비밀값까지 탐지하지 않는다.**

활성 하위 MCP는 `allowedTools`에 정확한 도구 이름을 명시해야 한다. 설명의 readOnlyHint는 권한이 아니다. 발견한 설명/스키마 변경은 현재 연결에서 격리하지만 서버 구현의 진실성이나 호스트 접근을 보장하지 않는다. [현재 정책·전환 안내](m2b-sensitive-mcp.ko.md)

[검증 기록](validation/m2b-boundaries-local.json)
