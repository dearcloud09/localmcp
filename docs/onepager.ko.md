## 이번 로컬 구현과 반영 경계
기존 파일 도구를 유지하면서 버전 해시 확인, 같은/상하위 경로의 공유 잠금, 작업 ID별 동일 요청 재전달을 구현했다. 서로 다른 파일은 병렬 처리한다. 동일 ID에 다른 인자가 오거나 실패했던 요청을 재실행하려 하면 거부한다. 기록은 프로세스 내 최대 1,024개이며 자동 만료/축출하지 않는다.

**이 코드는 아직 저장소에 설치되지 않았다.** GitHub 코드 생성 요청이 도구 보안 검사에서 차단됐고 우회 재시도하지 않았다. 검증한 소스·테스트 6개와 패치는 대화의 localmcp-m2c-review.zip에 보관한다. 이번 Git 갱신은 계획·진행표·검증 기록만 대상으로 하며 기존 실행 코드는 유지한다.

## 검증과 다음 관문
Linux/Node 22.16.0/UID 1000에서 새 37개+기존 25개를 **한 실행에서 62개 통과**했다. 독립 소스 strict 타입 검사, 이전 구현과 실제 파일 대조, 패치 적용 후 바이트 대조도 수행했다. 신규 SDK 통합 5개는 작성/미실행이며 전체 앱·macOS·Docker는 미검증이다. [이번 기록](validation/m2c-mutations-local.json)

E0/E1은 사용자 제공 근거이며 원시 도구 호출·승인 기록·맥 파일의 독립 감사가 아니다. chatgptActorVerified=false를 보존한다. [E0](validation/e0-macos-user-report.json) · [E1](validation/e1-local-check-user-report.json). 새 로컬 구현의 검사 결과와 과거 성공을 합산하지 않는다.

사용자가 밖에 있는 동안 맥 실행·앱 설정·이미지 설치를 요구하지 않는다. 다음은 코드 반영 경계 해소 후 새 변경의 누적 통합 검사, 별도 실제 Docker E0-D다. PR Draft 유지. CI 한도 증액/재실행·과금·공개 중계·배포·main 병합은 하지 않는다. Git 문서가 기준이며 MIT 고지를 유지한다.
