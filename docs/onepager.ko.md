## 최신 실측 근거와 수정
사용자가 제공한 report.json 내용과 전체 테스트 로그는 macOS / Node v23.11.0, revision 7a11495, dirtyWorkingTree=true를 보고한다. 타입 검사·빌드는 종료 코드 0이고 full-tests는 시간 초과가 아닌 종료 코드 1이다. 실패는 test/sensitive-paths.test.ts의 루트 이동/삭제 검사 하나이며, 새 M2c 모듈·config/Zod/SDK 통합 12개는 로그상 모두 성공했다.

원인은 새 변경 큐가 이동의 두 경로를 먼저 검사하면서 목적지 ../new를 거부해, 기존 루트 이동 거부보다 경로 이탈 오류가 먼저 반환되는 것이다. 이동이 허용된 결과가 아니고 macOS 전용 현상도 아니다. 로컬 수정본은 목적지 검사 전에 정규화한 출발지가 workspace 루트인지 먼저 거부한다. 기존 잠금·목적지 경계·내부 재검사는 유지하고 기존 테스트와 의존성은 바꾸지 않는다.

Linux / Node 22.16.0에서 기존 162개와 새 회귀 6개를 한 실행으로 검사해 **168개 통과**, 실패·취소·건너뜀 0. 독립 소스 strict 검사 통과. 이 결과를 사용자 macOS 전체 npm test 성공으로 대신하지 않는다. [실패·수정 근거](validation/m2c-root-order-local.json)

## 다음 관문과 기록 기준
사용자의 검사용 worktree에서 좁은 소스 수정 후 기존 민감 경로 검사, verify:minimum, 별도 E1 보조 검사를 실행한다. 현재 실패 때문에 test:profile/test:minimum-tools, 최종 mcp-smoke와 별도 E1 보조 검사는 아직 실행되지 않았다. 전체 성공 전 코드 push·main 병합·배포는 하지 않는다.

이번 원격 변경은 문서·검증 기록뿐이다. 기존 소스 업로드 차단을 재시도/우회하지 않았다. 사용자의 로컬 패치 적용과 원격 반영을 구분한다. npm의 high 경고 3개는 세부 advisory 미수신이며 이번 오류의 원인으로 단정하지 않는다. 자동 audit fix나 lockfile 변경은 하지 않았다. Git 문서가 기준이고 이전 검증 JSON은 당시 이력으로 보존한다. CI 한도/과금·공개 중계·Docker 이미지 설치 변경 없음. PR Draft·MIT 고지 유지.
