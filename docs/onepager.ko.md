## 목표와 구조
ChatGPT가 코딩 판단을 하고, LocalMCP 포크가 로컬 실행·권한·작업 기록·결과 전달을 담당한다. 기능은 모듈로 분리하되 별도 서버를 의무화하지 않는다.

`ChatGPT → MCP 입구 → 공통 코어 → 기능 모듈 → 내부 함수 / 기존 CLI / 필요한 하위 MCP`

파일 수정은 내부 코드, Git·테스트·빌드는 기존 CLI를 우선 사용한다. 전문 기능에만 하위 MCP를 추가하고, 자주 쓰는 기능은 직접 노출한다. 불필요한 모델·통신·발견 호출은 늘리지 않는다.

## M2a의 구체적 범위
`scripts/project-profile.mjs`의 `init`/`demo`/`doctor`는 로컬 설정 준비만 한다. 명시한 프로젝트만 지정하고, 설정을 프로젝트 밖에 새로 생성하며 기존 파일은 덮어쓰지 않는다. 생성 프로필은 **파일 쓰기는 허용**, 셸·지속 프로세스·Skills·하위 MCP는 비활성이다. 홈·루트·자격증명 디렉터리 중첩, 링크 우회와 위험한 환경변수 재정의를 점검한다.

**기존 `localmcp` 시작 명령의 기본값은 아직 변경하지 않았다.** 이 도구의 성공을 모든 실행 경로가 안전해졌다는 뜻으로 해석하면 안 된다. 실행 절차는 [M2a 가이드](m2a-project-profile.ko.md)를 사용한다.

## 검증·진행 규칙
코드와 테스트가 들어간 변경마다 이 표와 상세 진행표를 함께 갱신한다. 구현, 독립 검증, 전체 검사, 실제 연결을 분리해 기록하고 테스트 수를 서로 다른 환경에서 합산하지 않는다. CI는 **사용 한도 초과로 보류(사용자 확인)**하며 추가 비용 없이 진행한다. 미실행 CI나 교차 플랫폼 검증은 통과로 표시하지 않는다.
